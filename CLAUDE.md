# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is **Ressam**, a tabletop RPG (TTRPG) rulebook written in Markdown. The repository is content/rules-authoring - edits to game design text, tables, and formulas, not software. Every file under `core/` is plain hand-authored Markdown, edited directly - there is no build step or generated content anymore. (A prior version of this repo rendered the weapons/armor tables, spell lists, feat lists, and progression table from structured YAML via a Python + Jinja2 pipeline; that pipeline was removed once prototyping wrapped up, and its output was kept in place as ordinary Markdown.)

## Repository structure

- `core/core_rules.md` - foundational resolution mechanics: dice, attributes, skills, checks vs. Ward. **2026-08-23: the DC scale was recut from nine tiers to seven** on even 2-point steps (`4 / 6 / 8 / 10 / 12 / 14 / 16`, Very Easy through Legendary). **2026-09-20 (the Reach/Tempo rework): recut again, seven tiers down to four** - `5 / 7 / 9 / 11`, named Easy/Standard/Hard/Extreme, the same ladder `magic_overview.md`'s Lesser/Common/Greater/Legendary working tiers already used, so the two systems now share one difficulty table instead of two. Every roll is still `1d12` plus one 0-5 number, so the ceiling is still 17, and 2 points of DC is still exactly one step of one in six; only the number of named rungs changed - situational modifiers stack on top of a tier same as before, so real DCs in play still climb well past 11. **A Ward still takes a lower DC than a Skill Check** for the same fiction - set Wards one tier lower and keep unannounced hazards at Hard (9) or below, Extreme (11) reserved for named, telegraphed threats. Read this first; nearly every other chapter assumes these definitions. Two sibling chapters below split off what used to live here once the single file grew too dense: `rest_and_survival.md` and `exploration/stealth_and_light.md`. Basic Moves moved out to `combat/` in a 2026-08-10 reorg and were **deleted outright** by the 2026-08-23 Exchange merge (see the `core/combat/` bullet) - Dashing and Disengage survive in `positioning.md`, Grappling/Shoving/Disarming/Feint became Openings or attack types in `exchange.md`, and Shift Measure, Blind and Taunting are gone. **The `Contested Check` branch of Checks vs. Ward is now unused** - all four of its examples were combat maneuvers this rework deleted - and is kept explicitly labelled as an adjudication shape nothing calls. **The Attributes table's Tempo Pool/Initiative wording moved with the Reach/Tempo rework below** - DEX now funds Initiative and how hard you are to hit; STR is melee damage only, with nothing left to size in a fight.

Current shape: Carrying Capacity (one unified **Slots** pool, `6 + STR`, replacing the old Backpack Slots/Bulky Capacity split) and Rest & Repair (Short/Field/Long, now also repairing armor's Dent/Rend/Guard lines directly, folding in what used to be `armor.md`'s separate hourly Crafting-rank repair system) open the file, followed by Damage Types (Physical/Elemental/Occult unchanged, but Physical's three subtypes - Blunt/Piercing/Slashing - now each carry one real mechanical effect instead of just flavor), Wounds & Death's Door (Named vs. Unnamed characters, Wound Penalty, **Downed** replacing the old Death Clock/Coup de Grace/Stabilization chain outright, Falling, Food and Water, Suffocation - **Patched Wounds is gone**, healing now restores real Wounds directly), Trauma (widened **0-5 to 0-20**, shared with `magic_overview.md`, **no roll penalty at all** any more - it gates Scars and death only, and its main inflow is now healing itself: every Wound healed costs 1 Trauma), **Revelry & Leisure** (new - the only way Trauma comes down), Scars (reworked from damage-type-flavored/no-mechanical-effect to **Trauma-band-triggered with real mechanical effects** - Flinching, Haunted, Hollow, Wary, Hair-Trigger, Palsied, Steeled - tested with a CHA Resolve check), and Conditions (the full status-effect table, updated for Downed/Restrained-armor-bypass/Exerting). **Two new combat-adjacent systems live in `exchange.md` now but are documented from here:** Fear (a creature's Fear rating triggers a Will-funded resist on approach) and Morale/Nerve (CHA-funded, Named characters take Trauma instead of Breaking). **2026-08-23 (Exchange merge)** and **2026-08-30 (Dent/Rend Line rework)** history (STR-keyed Wound Threshold table, flat 2-Wound Unarmored rule) is superseded by the above - an unarmored target now reads Dent 0 / Rend 5 like any other armor value, a deliberate departure that lets a weak hit Turn Aside even unarmored.
- `core/character/` - building and advancing a character: `character_creation.md` (step-by-step guide), `attributes_and_skills.md` (reference glossary: what each of the 6 Attributes represents and what each Skill covers, grouped by category - the mechanics that use these numbers, like the Skill Check formula and DC tiers, stay in `core_rules.md` and are linked from here rather than duplicated), `knowledge.md` (what your character *knows*, as distinct from what they can *do* - a separate 24-subject, 3-tier None/Familiarity/Expertise system with no roll ever, chosen once at chargen and funded by a flat Freebie Pool plus curated Race/Career grants), `races/` (one hand-authored file per race, indexed by `races_overview.md` - see below), `careers.md`, `languages.md`, `progression_&_rewards.md` (the per-level advancement table, plus static prose covering Rewards & Treasure and Itemization). **2026-08-11/12: 8 Attributes became 6** - END merged into STR and PRE into DEX, leaving STR / DEX / MIND / ARC / FAI / CHA. The Skill list went the other way and split *further* rather than consolidating: per-weapon STR melee Skills (Two-Handed Blades, Cleaving Blades, Hafted & Polearms, Daggers & Wrestling) with **Fencing Blades** under DEX, **Ranged** and **Thrown** split apart, one Skill per Arcane and Divine school rather than a merged Arcanism/Devotion, **Thaumaturgy** absorbing Alchemy + Enchanting + Spell Crafting (Spell Crafting itself was deleted outright 2026-08-29 - see the `core/magic/` bullet below), and a new **Wayfaring**. **2026-08-23 (Exchange merge)** repointed the two combat Attributes at the Tempo Pool - **STR sizes your Tempo Die and is the whole of melee damage** (finesse blades included; only missiles take DEX), **DEX counts your dice** (`DEX \+ 1`) and buys nothing else, and **Initiative moved to MIND** (`5 \+ MIND`, static, never rolled). Wound Thresholds came off STR entirely. Athletics kept only the grapple-escape roll, Acrobatics lost its Shove/Grapple defense role, and Manipulate/Insight lost their Feint role (a Feint is now an attack type). **2026-08-23 (progression rework):** the Attributes rung of the priority ladder stopped being a point pool and became a **standard array** per letter (A `3, 2, 2, 1, 1, 0` down to E `1, 1, 1, 1, 0, 0`), assigned one number per Attribute with nothing to buy - much smaller numbers than the old 24/21/18/15/12 pool, which could only ever spend 18 anyway against a cap of 3. Attribute growth is a flat **\+1 to one Attribute at levels 4, 8 and 12**, hard cap 5, and the staged Attribute Maximum table is gone. **Attributes may now sit below 0** (the "below 0 and the character dies" rule is deleted; nothing damages an Attribute, so the only source is a racial \-1 on an array 0). **2026-09-20 (the Reach/Tempo rework) superseded the 2026-08-23 Exchange-merge paragraph above**: the Tempo Pool is no longer sized by DEX (or anything else) at all - it comes from the equipped weapon's (and shield's) Attacks modifier instead, flat `1d12`s throughout (see the `core/combat/` bullet) - and **Initiative moved off MIND onto DEX** (`5 \+ DEX`). STR stayed pure melee damage. `character_creation.md`'s Step 8 derived-stats table and `attributes_and_skills.md`'s per-Attribute prose were both updated to match; **Mana was renamed Will** (`MIND × 3`, was `MIND × 2`) and **Backpack Slots/Bulky Capacity merged into one Slots pool** (`6 + STR`, minimum 1, replacing the old `2 × STR` Backpack/`5 + Size` Bulky split) - see the `core/equipment/` and `core/rest_and_survival.md` bullets. Floors: **Will never below 0, Slots never below 1**; the Tempo Pool no longer reads an Attribute, so it has nothing left to floor. The Skill list also split further at the same time: **Hafted & Polearms became Hafted Weapons (Normal Reach) and Polearms (Reach 1/2)**, and **Ranged became Archery (bows and crossbows) and Firearms** (Thrown stayed separate, as it already was). `progression_&_rewards.md`'s per-level table had a stale six-number-array leftover from before the 2026-09-14 ARC/FAI deletion corrected to the real four-number array in the same pass. **Not yet touched by this rework - `core/feats/`, `core/character/races/`, `core/bestiary/`, and `templates/character/character_sheet.html`/`sheet_test.js` still describe the pre-rework mechanics** (old Weapon Length/Edge, old Tempo Pool formula, old Trauma 0-5 scale, old DC ladder in places, Ambushed/Caught Out Surprise, Death Clock/Stabilization) and are explicitly deferred to their own dedicated pass - see `TODO.md`.
  - `core/character/races/` - `races_overview.md` (hand-authored: General Rules Notes, Race Tiers A-E, and an index of races grouped by Artefolk/Cursed/Mystik/Night-Terror) plus one hand-authored file per race (`aelves.md`, `dwergaz.md`, `humans.md`, `orkhs.md`, `alsahli.md`, `feliids.md`, `skeggs.md`, `tembels.md`, `khoridae.md`, `dzinari.md`, `golems.md`, `tapio.md`, `daemons.md`, `varulf.md`, `strygs.md`). This split (one page per race, mirroring `core/magic/arcane/` and `core/magic/divine/`) exists to make individual races easier to manage and to leave room for per-race lore. **Not yet updated for the 2026-09-20 Reach/Tempo rework** (see above) - a dedicated pass, deliberately deferred.
- `core/combat/` - three files. Originally rebuilt wholesale at the **2026-08-23 Exchange merge**, which replaced the old Oppose/Reaction system; **rewritten again 2026-09-20 for the Reach/Tempo rework**, adapted from a standalone playtest draft (`combat_draft.md`, at the repo root alongside its companions `equipment_draft.md`/`magic_draft.md`/`spells_draft.md`) whose tested mechanics were adopted as the new mainline rules, with what the draft cut purely for its own one-shot slice (leveling, Feat-gating, the full weapon/armor list, Arcane/Divine flavor) reintegrated on top. The design log for the whole history is `exchange_log.md` at the repo root. Read `exchange.md` first - the other two assume it.
  - `exchange.md` - **melee combat entire, and the file that matters.** One resource, the **Tempo Pool** - `\+4` baseline plus the equipped weapon's (and shield's) Attacks modifier, every die a flat `1d12`, refilling in full at the **start of the round** (not your own turn) - pays for every attack, every defense, every Opportunity Attack, and Exerting; **there are no Reactions and no free defense of any kind**. **No Attribute sizes the pool any more** - STR is melee damage only, DEX funds Initiative and Shot DC instead. An Exchange is one attack and its answer, **defender rolls first**: the defender invests any number of dice into a **Parry** (or declines, DC 0) before the attacker invests at all; higher total wins, ties to the defender, **margin 5+ takes an Opening** (Riposte, Disarm, Sunder, Shove, Grapple, or a Feat) - **margin 3 for that weapon's own Signature Opening** (see `weapons.md`). **There are no critical hits anywhere in Ressam** - unchanged principle, margin only ever buys an Opening. Every melee hit that lands costs the target a Tempo Die (**Shock**). **Distance \& Reach replaced Weapon Length and the Edge mechanic outright**: every weapon now carries one of three **Reach** bands (Normal/Reach 1/Reach 2) with no reach-mismatch bonus of any kind - Opportunity Attack triggers (entering vs. leaving) and the Reach-2 strike-past-an-intervening-square clause are keyed off Reach instead of the old five-step Length ladder. **Initiative moved off MIND onto DEX** (`5 \+ DEX`, still static, never rolled); Mythic Initiative's core rule is unchanged. **Surprise's old two-rung Caught Out/Ambushed system is gone, replaced by Awareness** - a pure GM fictional call, not a roll or subsystem: an unaware target simply can't Parry the first attack against it (melee) or eats the Shot DC table's `\-3` row (ranged), and the ambush is spent after that one attack. **New: Fear** (a creature's Fear rating triggers a Will-funded resist the first time an enemy tries to close) **and Morale/Nerve** (CHA-funded, `1d12 + CHA` vs. Standard DC 7, tested on set triggers - Unnamed creatures **Break** on a fail, Named characters take Trauma instead and never Break) - both new subsystems with no equivalent in the pre-rework rules, documented here but referencing Trauma bands in `rest_and_survival.md`. **New: Exerting** - out of Tempo Dice but still need to Parry, invest a `1d6` and take 1 Trauma instead, capped at 1 Exert die per Parry. Ranged combat is still **not** an Exchange at all - now `1d12 + Archery/Firearms/Thrown Skill` (no Tempo Dice on either side) vs. a **Shot DC** built off `7 + target's DEX` plus situational modifiers, unanswerable, no Opening, no Shock - and its **Loading** ladder is unchanged in shape.
  - `combat.md` - what's left of the old chapter: action economy (no Reaction row, **Object Interaction kept as the name** rather than the draft's "Lesser Action"), the damage roll (**melee damage is STR for every weapon and Skill without exception; missiles take no Attribute at all now, not DEX**), a *There Are No Critical Hits* section that points at `exchange.md`, and armor's in-fight behavior - **Unarmored now reads Dent 0 / Rend 5 like a real armor value instead of a flat 2-Wound no-roll result** (see the `core/rest_and_survival.md` bullet), and the old firearm/War-Maul "costs 2 durability" special case is gone, folded into the general Blunt-damage-type rule (2x degradation) since firearms now get **Armor-Piercing** (a per-hit Dent/Rend reduction, see `weapons.md`) instead.
  - `positioning.md` - the grid, movement, and Cover. Cover stays **binary** and untouched. Reach 2 (ex-Pike) is now the only threat with a strike-past-an-intervening-square clause, same role the old Far Band/Length-5 pike held.
  - **Deleted by the 2026-08-23 merge:** `maneuvers.md` (Oppose, Stance, Effects, the Press, Reactive Casting) and `basic_moves.md`.

- `core/magic/` - spellcasting rules split into `laws_of_magic.md` (the in-fiction physics every spell, ritual, and minor working answers to - Five Laws that bound what magic can ever do (no true creation from nothing, no touching past/future, no making/unmaking/growing a soul, no rewriting essential nature by mortal craft, no effect without a thread of sight/touch/sympathy), Three Costs that price what's lawful but costly (Conservation, Signature, Reciprocity), and an Adjudication section for when the spell lists are silent on a player's novel idea - read this before ruling on anything not covered by an existing spell), `magic_overview.md` (universal rules shared by every school), and `minor_magic.md` (small, instinctive Will effects - minimum 1 Will, scaling in scale/duration from there - that fall outside a normal working), with two parallel school trees. **`spell_crafting.md` was deleted 2026-08-29** - the VERB+NOUN+MODIFIERS point-budget system for building custom spells was judged too much arithmetic load for what it bought (see `DESIGN_GUIDE.md`'s Elegance pillar) and cut outright rather than reworked; `TODO.md` folds what it was covering for (thin per-school spell counts) into the spell-list rebalance pass instead. **2026-09-20 (the Reach/Tempo rework): the casting engine itself was replaced wholesale**, adapted from a standalone playtest draft (`magic_draft.md`/`spells_draft.md` at the repo root) whose MESBG-inspired resolution was adopted over the rank-1-5/DC-`5+rank`/flat-Feat-bonus system the 2026-09-14 chassis had just built (see the `core/feats/` bullet's Magic Feats note) - that system is now superseded, not merely stale. **Mana was renamed Will throughout** (`MIND × 3`, was `MIND × 2`). The new shape: MIND is a hard **ceiling on dice committed** to any one cast or resist (never more dice than your MIND), not a modifier; casting commits Will 1-per-die (paid before rolling), rolls that many `1d12`s and takes the **highest**, against a flat DC set by the working's **tier** - Lesser/Common/Greater/Legendary at `5/7/9/11`, the same four numbers `core_rules.md`'s DC ladder now uses. A miss still spends the Will. **Push** (spend Trauma, `+1` per point to the highest die, max `+2`) and **Channel** (declared at the end of your prior turn, sets one die to the working's difficulty exactly, Trauma-costed by tier) are new. A targeted working is answered by the defender committing their own Will and rolling to **tie or beat** the caster's highest die - never a Ward, never a flat roll bonus from a Feat. Damage workings ignore armor outright (compare to Dent 0 / Rend 5 regardless of what's worn) and carry no damage type. **Not yet converted: the actual spell lists.** `magic/arcane/*.md` and `magic/divine/*.md` still describe every spell in the old Mana-Cost/flat-modifier/Spell-Attack-vs-Overcome shape and are now doubly stale (already flagged pre-rework in `TODO.md` for a rebalance pass; the casting engine swap makes every spell's numbers meaningless until that pass lands) - this is deliberately deferred, per-spell design work, not a mechanical find-and-replace.

  - `magic/divine/` - divine schools (benediction, cultivation, invocation, necration, subjugation) plus `divine_overview.md`.
- `core/feats/` - feat categories (general, martial, magic, prestige, skill, racial), indexed by `feats_overview.md`. **2026-09-14: Arcane Feats and Divine Feats merged into `magic_feats.md`** as part of the magic rework (see the `core/magic/` bullet below) - the category list above reflects this; historical notes elsewhere in this bullet that still say "arcane, divine" predate the merge. The same pass **deleted Thane's Brand from `prestige_feats.md` outright** (its whole premise - trading scroll-scribing for rune-branding - depended on scribing, which no longer exists for any school): Prestige Feats are down to 7, not 8. **2026-08-23: every prerequisite was re-cut against the standard array** (26 changed), and `feats_overview.md` now states the ceiling that keeps them honest: **no ordinary Feat asks for an Attribute above 2, no Feat asks for more than `\+3` ranks in a Skill, and a Prestige Feat may ask for 3 and no more** - because a prerequisite is a level gate in disguise (outside an **A** you start at 2, reach 3 at Level 4, 4 at Level 8), and **a Skill Rank requirement is an Attribute requirement too**, since Rank <= governing Attribute. To make a Feat harder to get, add a second requirement, never a bigger number. Every `4\+` gate is gone from the book; 27 Feats are live at Level 1, 24 at Level 4, and all Prestige Feats (8 as of this rule, now 7 post-2026-09-14) at Level 6 (the first Feat grant after their Level 5 unlock). `racial_feats.md` (added 2026-08-10) holds racial traits strong enough to cost a Feat slot instead of coming free with that race - grouped by race, gated by a `Race: <Name>` prerequisite. Currently holds two demoted death-cheat-tier Features: Humans' Indomitable Spirit (Tier E, unpaired - just an outright free-tier outlier) and Feliids' Nine Lives (Tier B, dropped to Tier D once Nine Lives left - its paired drawback Reckless Instinct was removed with it rather than left stranded, and Feliids got a new small Feature, Magnetic Charm, to backfill the vacated slot).

  **2026-09-20 (the Reach/Tempo rework): `magic_feats.md` alone was updated**, since it's mechanically load-bearing for the new casting engine (see the `core/magic/` bullet) - it gained a fourth Unlock tier (**Master**, gating Legendary-difficulty workings, Level 8) on top of Novice/Adept/Expert, and Focus Feats were redesigned around **Signature Workings** (a discounted, sometimes free-to-Channel working of your choice) rather than a flat roll bonus, since the new dice-count-based casting math has no slot for one. **`general_feats.md`, `martial_feats.md`, `skill_feats.md`, `prestige_feats.md`, `racial_feats.md`, and `feats_overview.md` were not touched** and still reference pre-rework mechanics in places - `prestige_feats.md` already caught referencing the deleted Ambushed/Caught Out Surprise rungs - and are deliberately deferred to their own dedicated pass alongside `core/character/races/` and `core/bestiary/` (see `TODO.md`).
- `core/equipment/` - `armor.md`, `weapons.md`, `supplies.md`, and `alchemy.md` (crafting oils/bombs/salves from ingredients). **2026-08-11:** Shields (the Shield Table/Descriptions/Guard rules, formerly `armor.md`'s own section) moved to `weapons.md` - a shield isn't armor, it's something you actively wield in a hand, and unlike armor it can now also be swung: a new **Shield Bash** attack (1d4 Blunt) uses the **Daggers & Wrestling Skill**, same as an unarmed strike. Shield repair still runs through the armor repair rules (shields share durability with armor, no separate track). **2026-08-23 (Exchange merge)** and **2026-08-30 (Dent/Rend Line rework)** history is summarized in the sections below, both now superseded in shape by the 2026-09-20 rework:

  **2026-09-20 (the Reach/Tempo rework):** adapted from `equipment_draft.md` (repo root), the same playtest draft `core/combat/`'s rework came from. `weapons.md`'s **Length \+ Edge system is gone, replaced by Reach** (Normal/Reach 1/Reach 2, see the `core/combat/` bullet) with no reach-mismatch bonus; the old margin-based **Opening column (Crit->Opening, `\-`/9/8)** is gone too, replaced by one **Signature Opening** per weapon (the specific Opening - Riposte/Disarm/Sunder/Shove/Grapple - that weapon reaches at margin 3 instead of 5). Every weapon also now prints an **Attacks** modifier (`\+1` Light / `\-1` Two-Handed / `\+0` else) that directly sets Tempo Pool size (see the `core/combat/` bullet) - a mechanical role Attacks never had before. **Skills split further**: the old combined **Hafted \& Polearms** is now **Hafted Weapons** (Normal Reach: Mace, Battle Axe, Club, War Maul, Greatclub, Whip, Weighted Chain, Chain Flail) and **Polearms** (Reach 1/2, every polearm reclassified off Normal Reach even Quarterstaff and Spear which used to fight Adjacent); **Ranged** split into **Archery** (bows and crossbows) and **Firearms** (guns), with **Thrown** unchanged. **Armor-Piercing was redefined**: it now lowers the target's Dent/Rend Lines by its AP value for that one hit (a bows-AP-2/crossbows-and-guns-AP-3-plus shape), rather than the old "degrades armor by 2 durability instead of 1" rule, which is deleted along with the matching War Maul special case (now redundant with the general Blunt-damage-type 2x-degradation rule). **Armor field repair moved out of `armor.md` entirely**, folded into `rest_and_survival.md`'s Rest \& Repair table (a flat \+1 per Field Rest, \+1 or \+2 on a Long Rest with a Smithing check) - the old hourly Crafting-rank repair system is deleted. **Shields gained an "Against shots" column** (a Heater Shield counts as Light cover against a shot at its bearer). **Carrying capacity unified**: `armor.md`/`weapons.md`'s Bulky Capacity references became a flat **1 Slot** each (equipped gear free), matching the new unified Slots pool (see the `core/character/` bullet). `alchemy.md`'s Vital Oil recipes were converted from granting **Patched Wounds** (now deleted, see the `core/rest_and_survival.md` bullet) to healing real Wounds at the same Trauma cost as any other healing; its Endurance Salve's old "removes Trauma via a Short Rest" effect was deleted outright, since **only Revelry \& Leisure removes Trauma now** - nothing in Alchemy is allowed to bypass that. `supplies.md`'s Medical Supplies section gained the Healing Draught entry (moved in from the equipment draft) and had its Chirurgery/Stabilization wording updated to match Downed. **`armor.md`'s Dent/Rend numbers themselves were deliberately left unchanged** - only the Unarmored *mechanic* changed (Dent 0 / Rend 5, a real roll, replacing the old flat 2-Wound no-roll result) - see the `core/rest_and_survival.md` bullet.

  Pre-2026-09-20 history, for context: **2026-08-23 (Exchange merge)** turned `weapons.md`'s Reach column into the four Measure Bands (since superseded by Distance \& Reach) and its Critical column into a Crit margin threshold (since superseded by Signature Openings); **2026-08-30 (Dent/Rend Line rework)** replaced the single AR number with the Dent Line/Rend Line pair still in use today (`Wound = old AR + 1`, `Deep = Wound + 4` - Gambeson 3/7, Chain Mail 6/10, Full Plate 9/13) and introduced the "every die at its maximum face finds a gap" rule, both still current. `core/bestiary/` was not touched by any of these passes, same precedent each time - see `exchange_log.md` item 66 and `TODO.md`.
- `core/exploration/` - travel and downtime layer: `traveling.md` (hex travel, mounts), `downtime.md` (revelry/celebrations), `leadership.md` (followers and cohorts), `dungeon_turns.md` (the 10-minute Turn as the clock for dungeon/site exploration - light tracking and wandering encounters share one party-wide tally), and `stealth_and_light.md` (Stealth and Hiding, Light and Vision - split out of `core_rules.md` and placed here since Light and Vision's burn-duration table already lived in lockstep with `dungeon_turns.md`'s Light Tracker). - `core/setting/` - the world of Ressam itself: `setting_overview.md` (welcome blurb, currency, language, and an index of this chapter - the `races_overview.md`/`feats_overview.md` pattern), `calendar.md` (the seasonal year and its festivals), `history.md` (Age of Mythos, the Sundering, Age of Revival, and the Third Age's wars up to 402 RC), `geography.md` (the Mourning Star and twin moons, the continents, and the Mortal Plane/Fields of Nocturne), `nations.md` (the great powers, the nation relations table, and global/local factions), `religions.md` (the faiths practiced across Ressam), and `heroes.md` (legendary figures). Cross-references a lot with `core/character/races/` - each race's own page covers that race's culture and mythology in more depth than fits here.
- `DESIGN_GUIDE.md` - the yardstick for evaluating any mechanic, item, spell, or rule change. **Read the three subsections under Scarcity before writing any number a player rolls against or has to reach**: they cover why a Feat slot is the cost and the prerequisite is only flavor, why the `1d12 \+ (0-5)` ceiling of 17 has to be checked before setting a DC or a threshold, and why a Ward must not be priced like a Skill Check. They also record the **5th Edition mirror** - Ressam's Attributes now map onto 5e's ability *modifiers* almost exactly (2 = a 14-15, 5 = a 20), and 5e's array in modifier terms is nearly our **C**'s, which makes 5e a usable sanity check for numbers of this shape: notably, every ability-score prerequisite in 5e is exactly 13, a \+1, and never higher. Five Design Pillars (Realism as "feel, don't simulate," Elegance, Scarcity, Niches, and Distinction between Martials and Casters), followed by Spell Design Guidelines covering damage caps (`Xd8 x Mana`, Pyromancy alone at `Xd10 x Mana`), the no-save-or-suck rule for Overcome spells, summoning being near-exclusive to Necromancy, per-school distinctiveness, Faith always being required for divine magic, healing defaulting to Patched Wounds, spells not bypassing mechanics for free, and Gish/spellblade playstyles being a Feat-driven compromise rather than something magic grants directly. Read this before proposing or reviewing changes to `core/magic/`, `core/feats/`, or `core/equipment/` - it's the reasoning behind *why* those files are shaped the way they are, not just what's in them. ## Publishing: GitHub Wiki

The rulebook is published as a GitHub Wiki, auto-synced from `core/` on every push to `main` via `.github/workflows/sync-wiki.yml`: the workflow clones the wiki's own git repo (`<repo>.wiki.git`), mirrors `core/`'s contents into it 1:1 (folder structure preserved, `core/` prefix stripped), and pushes only if something changed. **Never hand-edit wiki pages that correspond to a `core/**/*.md` file** - edits made directly in the wiki UI are silently overwritten on the next sync. Edit `core/` and let CI publish it.

Two pages exist **only** in the wiki repo, not in this one, and *are* meant to be hand-edited directly in the wiki UI: `Home.md` (landing page) and `_Sidebar.md` (persistent nav, shown on every page). The sync workflow explicitly excludes both from its mirror/delete step so it never overwrites them. Both list every chapter grouped by section, in the same order as "Repository structure" above. Local reference copies live at `templates/Home.md` and `templates/_Sidebar.md` for convenience - edit those first, then paste the result into the wiki UI. When a chapter is added, renamed, or removed under `core/`, update both pages (and their local copies) to match.

**GitHub Wiki quirk to know before editing either page:** wiki page URLs/links are flat and basename-only, regardless of which subfolder a file is mirrored into - e.g. `core/magic/arcane/pyromancy.md` is mirrored to `magic/arcane/pyromancy.md` in the wiki repo but renders at `/wiki/pyromancy`, not `/wiki/magic/arcane/pyromancy`. Multi-level nested paths in Markdown links (e.g. `[Pyromancy](magic/arcane/pyromancy)`) 404. Always link to wiki pages by bare filename with no folder prefix and no `.md` extension, e.g. `[Pyromancy](pyromancy)`. This only works because every `core/**/*.md` basename is unique repo-wide - if that ever stops being true, this linking scheme needs to be revisited.

## Content conventions

- Em Dashes (—) and En Dashes (–) are not used, instead use only Hyphens (-).
- Files are exported from Google Docs, so literal Markdown-special characters are backslash-escaped in the source (e.g. `1d12 \+ Skill Ranks \+ Attribute`, `Ressam is not Dungeons \& Dragons`, `Slots \= STR \+ END`). Preserve this escaping style when editing existing text so re-exports/diffs stay clean.
- Formulas and derived stats are given as bolded inline math (e.g. `**Maximum Wounds = Size baseline + Feats**`) rather than code blocks. Follow this pattern for new formulas.
- Section breaks use a horizontal rule (`---`) between major topics within a chapter.
- Tables are used heavily for skill lists, DC tiers, and comparative mechanics (e.g. Arcane vs. Divine casting) - match existing table shapes when adding related content instead of introducing prose where a table already exists for that topic.
- **A `[[Display Text|PageName]]` wiki link inside a table cell breaks the table** - the `|` in the link syntax reads as a column separator to the table parser. Inside a table cell, link with the pipe-free form `[[PageName]]` instead (it displays the bare page name, e.g. `[[exchange]]`) and put whatever display text is needed in the surrounding cell prose - e.g. `see Grappling in [[exchange]]`, not `see [[Grappling|exchange]]`. Outside a table this isn't an issue; `[[Display Text|PageName]]` is fine in ordinary prose.
- Core terminology is reused verbatim across chapters (e.g. `Major Action`, `Ward`, `Dent Line`/`Rend Line`, `Trauma`, `Will`, `Reach`, `Attacks`) - when editing one chapter, check whether the same term/mechanic is defined or referenced elsewhere (`core_rules.md`, `rest_and_survival.md`, `combat.md`, `exchange.md`, `magic_overview.md`) so definitions stay consistent. `AR`, `Evasion`, and `Mana` are retired terms from earlier reworks (AR/Evasion by the Exchange merge, Mana renamed Will by the 2026-09-20 Reach/Tempo rework) - don't reintroduce them in new text.
- The game's tone/scope per `core_rules.md`'s foreword: Ressam is a crunchy, lethal alternative to other TTRPGs, set in a world balanced around an early-1500s baseline - matchlock firearms sit alongside plate armor, magic is feared and regulated. Combat is the heart of the game; everything outside of it is meant to be played loosely, "rulings not rules."
- **2026-09-14, prose style:** `core/` text should read as a table reference, not a teaching text - state each rule once, in the fewest words that remove ambiguity. Cut sentences that explain *why* a rule is shaped the way it is (that belongs in `DESIGN_GUIDE.md`/`exchange_log.md`, not `core/`) unless removing the sentence would let a reader reasonably misapply the rule - see `DESIGN_GUIDE.md`'s Prose Style section for the full litmus test and worked examples. Default edge cases to a GM ruling instead of an enumerated sub-case, and prefer tables/bullets over prose past two comparable items. This targets prose density only, not mechanical scope - Ressam's crunch stays; the words around it don't. Piloted against `exchange.md` as a sample; not yet applied repo-wide (see `TODO.md`).
